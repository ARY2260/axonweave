# AxonWeave Documentation

**A trainable sparse biological neural substrate built around the MaleCNS v1.0 connectome.**

AxonWeave lets a user provision the published connectome, load it as a reusable substrate, train edge parameters, and compose the substrate with ordinary framework-native layers.

:::DOC-NOTE
The connectome is a structural scientific source. AxonWeave makes computational assumptions explicit rather than presenting an incomplete biophysical model as exact biological simulation.
:::

## Install AxonWeave

```bash
pip install axonweave
axonweave substrate install male-cns:v1.0
```
